# win-deck

デスクトップ PC にタッチ対応モバイルモニター（VisionOwl MD-14T など）をつなぎ、
Steam Deck のように手元の画面だけでゲームを選んで遊ぶための Windows 用ランチャーです。

Tauri 2（Rust）＋ React / TypeScript で作っています。

## 機能

- **Deck モード**: 指定したモニターにランチャーを全画面で表示します。プライマリや画面配置は変更しません。
- **ゲームウィンドウの移動**: ゲームの起動から 2 分間、前面に出たゲームのウィンドウを Deck 用モニターへ移動します。
  ボーダーレス全画面のゲームは、モニターいっぱいに合わせます。
- **モニターの自動切替**: モニターを接続すると自動で Deck モードに入ります（設定でオン/オフ）。
- **ゲームランチャー**: Steam（カバー画像付き）と Epic のインストール済みゲームを自動で表示します。
  任意の exe / lnk も追加できます。
- **クイック設定**: 画面右端のボタンから開きます。中身は音量・ミュート、明るさ（DDC/CI。非対応ならソフトウェア減光）、
  解像度・リフレッシュレート、電源プラン、ホームに戻る、です。
- タスクトレイに常駐し、トレイから Deck モードの開始/終了や、アプリの終了ができます。

## 使い方

1. `npm install`
2. `npm run tauri dev`（開発用）または `npm run tauri build`（インストーラーを作成）
3. 「設定」タブで Deck 用モニターを選びます。MD-14T は EDID に名前がなく `RTK1920` のように表示されることがあります。
4. タッチがメインモニターに反応する場合は、「タッチ画面のセットアップを開く」から MD-14T を登録します。
5. 「Deck モード開始」をタップします。

## 必要なもの（開発）

- Rust（stable, MSVC）
- Visual Studio 2022 の「C++ によるデスクトップ開発」ワークロード（Windows SDK を含む）
- Node.js

## 既知の制限

- **排他フルスクリーンのゲーム**は、Deck 用モニターに移動できないことがあります。また、クイック設定のボタンもその上には表示できません。
  ゲーム側でボーダーレス（ウィンドウ化フルスクリーン）かウィンドウモードを選んでください。
- 管理者権限で動くゲームは、ウィンドウを移動できません（Windows の UIPI による制限）。
- ゲームによっては、移動した後に解像度が自動で追従しないことがあります。その場合は、ゲーム内で解像度を 1920×1080 などに合わせてください。
- ソフトウェア減光は、Windows の制限で 50% 程度までしか暗くできません。
- 解像度の変更は一時的なもので、再起動すると元に戻ります。
